# 코드 리뷰 및 사용성 검증 결과

2026-09-18에 `client/`와 `server/`의 애플리케이션, 마이그레이션, 배포 스크립트, 테스트를 검토했다. 아래 발견 사항은 모두 로컬 코드에 수정 반영했다. 작업 폴더에 Git 메타데이터가 없어 커밋은 생성하지 않았다.

| 번호 | 발견 사항 | 수정 및 검증 |
| --- | --- | --- |
| 1 | 대화를 빠르게 전환하면 이전 요청의 응답이 선택한 대화를 덮어씀 | 탐색 요청 순서를 확인하고 최신 응답만 적용. 지연 응답을 사용한 브라우저 검증 통과 |
| 2 | 업로드 중 이동과 중복 작업으로 다른 대화의 파일이 입력창에 나타날 수 있음 | 작업 잠금과 이동 제한 추가. 파일 개수와 크기를 전송 전에 검사하고 서버 설정을 사용 |
| 3 | 진행 중인 대화를 다시 열거나 중복 요청 응답을 받으면 중단할 실행 ID가 없음 | 저장된 실행을 이어서 조회하고 중단 대상으로 등록. 다시 연 실행의 중단 검증 통과 |
| 4 | 연결 실패와 재시도에서 임시 답변이 남거나 전송한 초안이 유지됨 | 수락 시 초안 정리. 실패한 임시 메시지 제거. 실행 ID가 있으면 저장 상태를 확인 |
| 5 | 프록시의 HTML 오류가 JSON 파싱 오류로 표시됨 | 공통 오류 변환으로 한국어 안내 제공. 초안 보존과 재전송 검증 통과 |
| 6 | CRLF가 네트워크 청크 사이에서 분리되면 SSE 이벤트를 읽지 못함 | 합친 버퍼에서 줄바꿈 정규화. 한국어를 바이트 단위로 나눈 회귀 테스트 통과 |
| 7 | 대화 삭제 실패가 확인창 밖에 표시되고 Promise 오류가 처리되지 않음 | 확인창 안에 오류 표시. 대기 중 닫기 제한. 실패 후 취소 검증 통과 |
| 8 | 브라우저 저장소 접근 거부가 초기 로딩을 중단함 | 저장소 접근 보호. 세션 만료 시 남은 로딩과 초안 상태 정리 |
| 9 | 추출 완료 저장과 파일 삭제가 겹치면 삭제한 텍스트가 복원될 수 있음 | 추출 작업의 첨부 행에 잠금 적용. 미완료 삭제 트랜잭션과의 경합 테스트 통과 |
| 10 | 워커 취소 시 추출 하위 프로세스가 남음 | 취소 시 프로세스 종료와 회수. 회귀 테스트 통과 |
| 11 | 허용된 길이의 한국어 답변과 추출문이 MySQL TEXT의 바이트 용량을 초과함 | MEDIUMTEXT로 변경하는 마이그레이션 0003 추가. 긴 한국어 저장 및 실제 마이그레이션 검증 통과 |
| 12 | 모델 호출 직전 취소해도 예약 비용이 남고 반복 취소가 정리를 방해함 | 호출 전 취소는 비용 0으로 정산. 취소 요청을 행 잠금으로 한 번만 처리. 회귀 테스트 통과 |
| 13 | 공급자 스트림이 갑자기 끝나도 완료로 처리됨 | 종료 이벤트 없는 EOF와 잘못된 이벤트를 공급자 오류로 처리. 회귀 테스트 통과 |
| 14 | 도구 계획이 마지막 모델 호출 횟수까지 소모할 수 있음 | 최종 답변용 호출을 확보. 한 번만 호출 가능한 설정에서도 자료 기반 답변 검증 |
| 15 | 캐시 읽기 가격이 입력 가격보다 높은 모델을 허용함 | 캐시 읽기와 쓰기 모두 가격 상한 검사. 회귀 테스트 통과 |
| 16 | 잘못된 목록 커서가 서버 오류를 유발함 | 구조와 날짜, UUID를 검증하고 입력 오류로 반환. 회귀 테스트 통과 |
| 17 | 계정 삭제 직전에 인증된 요청이 삭제 후 대화를 생성할 수 있음 | 생성 시 잠금 후 계정 재확인. 대화 조회에서도 삭제된 소유자 제외 |
| 18 | 공유 테스트 DB 초기화가 중첩되어 외래 키 생성 오류가 발생함 | 세션당 스키마 생성 후 데이터만 정리. 테스트 프로세스 간 파일 잠금 추가. 운영 DB와의 이름 중복 차단 |
| 19 | Paramiko 4.0.0에 SHA-1 관련 공개 취약점이 있음 | 5.0.0으로 갱신하고 잠금 파일 반영. 의존성 감사 및 읽기 전용 SSH 접속 검증 통과 |
| 20 | SSH 명령의 stderr가 차면 stdout 읽기가 멈출 수 있음 | 채널을 합쳐 함께 읽도록 수정 |
| 21 | 작은 화면의 확인창 버튼이 넘치거나 iOS 입력 시 화면이 확대될 수 있음 | 버튼 줄바꿈과 모바일 입력 글자 크기 보정. 대화상자 배경 및 포커스 검증 |

추가로 DB 예외의 SQL 인자를 숨기고, 업로드 디렉터리 생성 실패를 정리 경로에 포함했다. 실행 잠금 행이 없으면 요청을 거절한다. 파일 상태 조회의 중복 실행을 막고 비공개 파일의 Git 제외 규칙도 보완했다.

검증 결과:

- 백엔드: `uv run ruff check backend tests scripts` 통과. `uv run pytest -q` 80개 통과.
- 프런트엔드: `npm test` 3개 통과. 타입 검사와 프로덕션 빌드 통과.
- 의존성: `npm audit --omit=dev` 및 Python 환경 `pip-audit`에서 알려진 취약점 0개.
- 브라우저: 지연 응답 경합, 실행 재개와 중단, 전송 오류, 삭제 오류, 업로드 이동 제한, 미리보기, 음성 동의 검증.
- 화면: 360px, 768px, 1440px에서 밝은 화면과 어두운 화면 확인. 가로 넘침 없음. Escape로 확인창을 닫은 뒤 포커스 복귀 확인.
- 통합: 별도 검증 DB에 0001부터 0003까지 적용. 실제 Next.js 프록시와 FastAPI, MariaDB, 추출 워커로 게스트 접속, TXT 업로드, 미리보기, 답변 저장, 새로고침 후 재열기, 대화 삭제, 계정 삭제 통과. 페이지 JavaScript 오류 없음.

통합 검증의 LLM 응답은 결정적인 대체 구현을 사용했다. 이번 검증으로 실제 외부 모델의 답변 품질이나 Google 로그인, 물리적 마이크와 스피커 동작을 검증했다고 주장하지 않는다. 기존 문서의 공급자 계정 한도 설정 문제는 별도 운영 항목이다.

운영 배포는 수행하지 않았다. 운영 반영 시 `server/`에서 `uv run alembic upgrade head`로 마이그레이션 0003을 먼저 적용해야 한다. 테스트에는 Authlib의 의존성 폐기 예정 안내와 이미지 크기 제한을 의도적으로 넘기는 테스트의 경고가 남으며 실패는 없다.

Base UI 대화상자는 로컬 Peer Design의 `examples/base-ui/components/alert-dialog/demos/hero/css-modules/index.tsx`와 `examples/base-ui/components/dialog/demos/hero/css-modules/index.module.css`를 참고했다. Paramiko 변경 근거는 [공식 5.0.0 변경 기록](https://www.paramiko.org/changelog.html)이다.
