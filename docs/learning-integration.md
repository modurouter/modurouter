# modurouter 학습 연계 제안

2026-09-18. 평생교육이용권과 AI 디지털배움터의 역할을 현재 LLM 채팅·음성 입력에 연결하는 제안. 기관 연동 계약이나 공식 수료 연동은 아직 없다.

## 핵심 경험: 수업이 끝나도 이어지는 실습

공식 사이트는 교육 검색과 신청을 맡고, modurouter는 학습자가 직접 과제를 수행하는 동안 도움을 제공한다. 첫 실증은 배움터 강사가 수업 끝에 QR로 과제를 배포하고, 학습자는 집에서 같은 연습을 이어가는 흐름으로 구성한다.

1. 강사가 과제 링크/QR을 배포한다. 과제 ID, 버전, 학습 목표, 성공 조건만 포함한다.
2. 학습자가 상단 AI 디지털배움터에서 과제를 연다. 음성 입력과 기존 모드별 글자 크기를 사용한다.
3. 연습 화면의 선택과 실제 결과를 확인한다. LLM은 한 번에 한 가지 질문/힌트를 제공한다.
4. 막힌 단계에서 힌트 → 시범 → 다시 혼자 수행으로 진행한다.
5. 완수한 결과물과 다음 연습을 남긴다. 기관에는 동의한 범위의 완료 여부·도움 횟수·비용을 전달한다.

## 먼저 만들 과제

| 과제 | 직접 하는 행동 | 완료 근거 |
| --- | --- | --- |
| AI 질문 다듬기 | 목적·상황·원하는 결과를 넣어 질문을 고치고 답 비교 | 실제 수정한 질문과 사용자가 선택한 결과 |
| 키오스크 주문 연습 | 모의 화면에서 포장·메뉴·수량·주문 확인 선택 | 시뮬레이터 상태의 목표 주문 일치; 실결제 없음 |
| 수업 후 복습 | 배움터에서 받은 과제를 다른 예제로 다시 수행 | 과제별 정해진 완료 조건과 재시도 기록 |
| 평생교육 학습계획 | 배우려는 일·가능 시간으로 계획을 만들고 강좌 후보 비교 | 저장한 계획과 실제 결과물; 공식 수료와 구분 |

노약자 모드에서는 한 단계와 큰 선택지, 어린이 모드에서는 짧은 상황 과제, 학생 모드에서는 더 적은 힌트와 결과 비교를 기본으로 한다. 연령 모드만으로 실제 역량을 단정하지 않고 사용자가 난이도를 바꿀 수 있게 한다.

## 평생교육이용권 연결

‘평생교육이용원’은 문맥상 평생교육이용권으로 해석했다. 학습계획 → 사용기관/강좌 확인 → 신청 준비 → 수강 중 실습 → 수강 후 반복 연습 흐름을 제안한다.

등록된 사용기관과 협력해 강좌에 modurouter 실습을 포함하는 방식부터 검토한다. 일반 AI 사용료를 이용권으로 바로 결제하거나 공적 이용권 잔액을 자체 크레딧으로 전환할 수 있다고 가정하지 않는다. 대상 여부·가맹/사용기관·강좌 인정·정산은 공식 기준과 기관 협의 후 연결한다. 초기에는 사용자 자기신고 진행 표시와 공식 신청 페이지 연결만 제공한다.

## 구현 단계

2026-09-18 추가: 학습 스튜디오의 9개 활동과 `learning_sessions` 서버 저장, 활동별 코치 대화 연결을 구현했다. 아래의 초기 제안 중 학생 모드에 해당하는 범위는 [모드별 학습 공간](mode-learning.md)의 최신 구현 내용을 따른다. 기관 연계와 강사 배포 흐름은 여전히 제안 단계다.

- 현재: 모드별 liquid-dom 진입 버튼, Base UI 학습 영역, Motion 로고 흐름. 주문 연습·AI 탐정·오답 복습을 단계별 예제로 제공하고 진행·완료를 브라우저에 저장한다. 버튼·음성으로 활동을 선택하고 자유 활동은 기존 AI 채팅에 바로 연결한다. 생활 배움터에 공식 교육/이용권 링크를 제공한다. 별도의 외부 API 인증·신청·수료 연결 없음. 구체적인 구현 범위는 [모드별 학습 공간](mode-learning.md)을 참고한다.
- 다음: `learning_tasks` 버전별 목표/단계/완료 조건, `learning_sessions`의 현재 단계/힌트/결과물. 과제 컨텍스트는 서버가 ID로 해석해 모델 요청에 주입하고 일반 대화와 분리. 키오스크 모의 화면부터 실제 상태 기반 완료 검증.
- 현장 실증: 강사용 과제 QR, 사용자가 동의한 완료 리포트, 기관별 예산 한도. 콘텐츠 재사용·API·수료/신청 연동은 제공기관과 확인 후 구현.

비용: 버튼 선택·화면 전환·정답 상태 확인에는 모델을 호출하지 않는다. 새 설명/힌트가 필요할 때만 저비용 모델을 호출하고 과제별 토큰/도구/음성 비용을 기존 일일 한도에 합산한다. 공식 수료는 LLM의 판단으로 발급하지 않는다.
