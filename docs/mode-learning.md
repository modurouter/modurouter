# 모드별 학습 공간

- 노약자: 생활 배움터 / 주문 연습 / 기존 생활·스마트폰 활동
- 어린이: 호기심 교실 / AI 탐정 / 탐구·이야기·AI 이해 활동
- 학생: 학습 스튜디오 / 오답 복습 / 공부·탐구·AI 활용 활동

대표 실습은 클라이언트에 정의한 예제로 단계별 선택과 힌트를 제공한다. 실제 주문이나 자동 생성 문제는 아니다. 완료는 마지막 단계를 통과할 때만 기록하며, 모드별 진행과 완료 횟수는 `modurouter.learning.v1`로 현재 브라우저에 저장한다. 기록 지우기는 해당 모드만 초기화한다. 서버 학습 기록, 기관 인증, 교육기관 수업 코드 및 지원금 연계는 구현하지 않았다.

음성 전사 결과와 입력창의 선택지 입력은 동일한 실습 상태 전이를 사용한다. 실습 단계 자체는 LLM 호출이 없고, 음성 사용 시에는 기존 STT 비용이 발생한다. 자유 활동은 기존 LLM 채팅 및 첨부 경로로 연결한다. 화면에는 활동명만 표시하고 모드별 지도 방식과 선택 활동의 지침을 요청에 포함한다. 서버의 기존 12,000자 한도를 넘는 경우에는 사용자 원문을 보존하고 추가 지침을 생략한다.

확인: 단계 진행·오답 힌트·완료·음성 선택 해석·모드별 목록·저장 값 복구 단위 테스트, 요청 payload와 표시 문구 분리 테스트. 실제 브라우저에서 세 모드 전환, 실습 진행, 새로고침 이어 하기, 390px 화면의 가로 넘침과 내부 스크롤 없음 확인. 실제 마이크 녹음 및 유료 LLM 응답 품질은 이 변경에서 추가 검증하지 않았다.
