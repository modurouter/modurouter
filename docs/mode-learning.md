# 모드별 학습 공간

생활 배움터와 호기심 교실의 대표 실습은 기존 클라이언트 예제를 사용합니다. 이 두 모드의 진도는 현재 브라우저의 `modurouter.learning.v1`에 저장합니다.

## 학습 스튜디오

PR #8의 공부 코치, 탐구와 발표, AI 활용 구성을 이어서 구현했습니다.

| 분야 | 활동 | 결과물 |
| --- | --- | --- |
| 공부 코치 | 오답 복습, 내 문제로 복습 | 분배법칙 복습 노트, 내 문제 오답 노트 |
| 공부 코치 | 개념 이해하기, 복습 계획 | 개념 설명 노트, 복습 일정 |
| 탐구와 발표 | 탐구 주제 찾기, 자료 비교하기, 발표 준비하기 | 탐구 설계, 자료 비교표, 발표 개요 |
| AI 활용 | 질문 다듬기, 출처 확인하기 | 개선한 질문, 출처 확인 기록 |

각 활동은 서버가 제공하는 설명과 예제, 3~4단계 과제로 구성됩니다. 선택형 문제는 정답을 서버에서 확인하며 틀리면 힌트를 보여 줍니다. 작성형은 10~3,000자의 답안을 저장하고 다음 단계로 넘어갑니다. 작성형 제출은 정답 인증을 뜻하지 않으며 AI 코치에게 추가 검토를 요청할 수 있습니다.

답안 저장으로 초안을 보관하고 새로고침 후 최근 활동을 이어 갑니다. 모든 단계를 마치면 결과물을 Markdown으로 내려받습니다. 다시 연습해도 완료 횟수와 직전 완료 노트는 유지합니다. 기록 삭제는 확인 후 해당 활동의 기록만 지우며 코치 대화는 대화 기록에서 별도로 관리합니다. 계정 삭제 시 학습 기록도 삭제합니다.

코치 대화는 활동별로 분리합니다. 서버가 대화에 연결된 활동과 현재 단계, 저장한 답안을 모델 문맥에 넣습니다. 따라서 새로고침하거나 지난 대화를 열어도 학습 맥락을 복원합니다. 대화에서는 기존 첨부와 검색, 모델 선택 기능을 그대로 사용합니다. 단계 선택과 기록 저장에는 모델을 호출하지 않습니다. 코치 응답과 음성 전사는 기존 사용 한도에 포함합니다.

음성으로 활동 이름과 선택지를 고를 수 있고 작성형 단계에서는 전사 내용을 답안에 넣습니다. 답안은 확인 후 저장합니다. 채팅의 Enter는 모든 모드에서 줄바꿈이며 전송 버튼으로 보냅니다. 학습 스튜디오가 열려 있을 때 채팅 입력을 전송하면 현재 단계의 답안 입력으로 처리합니다.

## 저장과 배포

`0009_learning_sessions` 마이그레이션이 필요합니다. 학습 데이터는 계정별로 분리하고 쿠키 세션과 CSRF를 검증합니다. 게스트는 현재 세션으로 이어 하며 쿠키를 삭제하면 기록에 다시 접근할 수 없습니다. 게스트에서 Google 계정으로 자동 이전하는 기능은 포함하지 않습니다. 동시 수정은 revision 충돌로 처리하고 같은 저장 요청의 재전송은 한 번만 반영합니다.

기관 인증이나 공식 수료, 교육기관 등록과 지원금 연계는 제공하지 않습니다.

## 검증

서버 테스트는 9개 활동 전체의 시작과 완료를 검증합니다. 오답과 초안 저장, 소유권과 CSRF, 중복 요청과 동시 수정, 코치 대화 연결과 기록 삭제도 확인합니다. 브라우저에서는 실제 API와 테스트 데이터베이스로 저장과 복원, 노트 다운로드와 코치 연결을 점검했습니다. 브라우저의 모델 응답에는 검증용 어댑터를 사용했으며 실제 유료 모델의 답변 품질이나 마이크 녹음은 이번 검증에 포함하지 않았습니다.
